# QuizMaster – Interactive Quiz Website

## About the Project
QuizMaster is a responsive and interactive quiz website developed using HTML, CSS, and JavaScript. It allows users to test their knowledge through multiple-choice questions and receive instant feedback.

## Features
- Interactive multiple-choice questions
- 10 questions loaded from a JSON file
- Instant correct and incorrect answer feedback
- Color-coded answer options
- Real-time score tracking
- Question progress indicator
- Explanations for incorrect answers
- Final score and performance message
- Restart quiz without reloading the page
- Responsive design for mobile and desktop screens

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON
- Bootstrap: Not used

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Click Start Quiz to begin.

## Learning Outcomes
- Understanding HTML structure and CSS styling
- Working with JavaScript events and DOM manipulation
- Loading external JSON data using Fetch API
- Managing quiz state and score dynamically
- Creating responsive web interfaces
